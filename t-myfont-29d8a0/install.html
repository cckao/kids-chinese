HOW TO INSTALL

手寫字型安裝教學

MY HANDWRITING FONT ・ 國語生字學習站

在「寫寫字」寫好字以後，可以把自己的字裝到電腦（Windows、Mac），在 Word、簡報裡打出自己的字。

先知道：裝好的字型會出現在 Word、PowerPoint、Pages、Keynote 這些會列出電腦字型的軟體。Google 文件、Canva 這類網頁版軟體沒辦法用。
教學 1

iPhone、iPad：一個按鈕直接安裝

不用下載其他 App。字型會包成一個「描述檔」，在「設定」允許後就裝好了。

1用 Safari 打開學習站的「寫寫字」，按「iPhone／iPad：直接安裝到手機」。

在 LINE、IG、FB 裡點開的網頁不行，請按右下角「⋯」選「用 Safari 開啟」。

2跳出「要下載描述檔嗎？」時，按「允許」，再按「關閉」。

這時候還沒裝好，要到「設定」完成下一步。

3打開「設定」，最上面會出現「已下載描述檔」，點它。

沒看到的話：設定 →「一般」→「VPN 與裝置管理」，點「字型：○○的字」。

4按右上角「安裝」，輸入手機密碼，再按一次「安裝」→「完成」。

畫面寫「未簽署」是正常的，自己做的字型都會這樣。描述檔裡只有字型，不會改手機的其他設定。

5打開要用的 App（已經開著的話，先關掉再重開），在字型清單找「○○的字」。

裝好以後，哪些 App 可以用？

  • 可以：字型清單會列出「手機裡的字型」的 App，例如 Pages、Keynote、Word、GoodNotes、Procreate。
  • 標籤機 App：要看那個 App。字型清單有「系統字型」「本機字型」或會列出手機裡的字型，就找得到「○○的字」；如果只有 App 自己提供的字型，就找不到。最快的方法是裝好以後打開標籤機 App 的字型清單找找看。
  • 不行：IG、LINE、FB 和手機的系統字型。
教學 2

Android 手機、平板：在 App 裡匯入

大部分 Android 手機不能把下載的字型裝成整台手機都能用的字型，要在 App 裡匯入。

1在「寫寫字」按「做成字型檔並下載」，檔案會存到「下載」資料夾，檔名像「○○的字.otf」。
2打開要用的 App（例如標籤機 App），到文字或字型設定，找「匯入字型」「自訂字型」或「新增字型」。
3從「下載」選「○○的字.otf」，字型清單就會出現「○○的字」。

裝好以後，哪些 App 可以用？

  • 可以：有「匯入字型」功能的 App，例如部分標籤機、繪圖、修圖、筆記 App。匯入到哪個 App，就只能在那個 App 用。
  • 標籤機 App：沒有「匯入字型」功能的話就不能用，可以問標籤機廠商，或改用電腦版軟體。
  • 不行：IG、LINE、FB 和手機的系統字型。
安裝教學

電腦：Windows、Mac

在「寫寫字」按「做成字型檔並下載」，再照你的電腦安裝。電腦裝好以後，大部分軟體都能用。

1打開「檔案總管」→「下載」，找到「○○的字.otf」。

2在檔案上按右鍵，選「安裝」。

Windows 11 沒看到「安裝」的話，先點「顯示其他選項」。也可以點兩下打開預覽，再按左上角「安裝」。

3打開 Word 或 PowerPoint（已經開著的話，先關掉再重開），在字型選單找「○○的字」。

1打開「Finder」→「下載項目」，點兩下「○○的字.otf」。

2會打開「字體簿」的預覽視窗，按右下角「安裝字體」。

如果跳出「字體驗證」警告，手寫字型常會這樣，勾選後按「安裝已勾選的項目」。

3打開 Pages、Keynote 或 Word（已經開著的話，先關掉再重開），在字型選單找「○○的字」。

往左滑看下一步

裝好以後，哪些軟體可以用？

  • 可以：Word、PowerPoint、Pages、Keynote、Illustrator 等會列出電腦字型的軟體。
  • 不行：Google 文件、Canva 免費版這類網頁版軟體。

小提醒

  • 還沒寫過的字，會自動用其他字型顯示。多寫一些字，看起來會更完整。
  • 寫了更多字以後，重新下載字型檔再安裝一次，就會換成新的。勾選「字型名稱加上編號」，新舊字型才不會搞混。
  • 文件傳給別人時，對方沒有這個字型就會變成別的字。先存成 PDF 再傳，就能保留自己的字。
  • 不想要了：Windows 到「設定 → 個人化 → 字型」解除安裝；Mac 在字體簿刪除。
