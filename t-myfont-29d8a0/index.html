OTF

下載我的字型

把寫過的字做成字型檔（○○的字.otf），裝到電腦就能在 Word、簡報打出自己的字。手機、平板也能下載存到「檔案」。

每次下載都會變成新名字，例如「○○的字 1115-2」。重新安裝時電腦才不會一直顯示舊的字型，也比較不會裝不起來。

iPhone、iPad 請用 Safari 打開學習站再按。會跳出「要下載描述檔嗎？」，按「允許」，再到「設定」安裝，步驟看安裝教學。

HOW TO

把我的字型裝到電腦、手機

看圖文安裝教學（iPhone、iPad、電腦）

下載的字型檔叫做「○○的字.otf」。裝好以後，在 Word、PowerPoint、Pages 都能用自己的字打字。

  1. 打開「檔案總管」→「下載」資料夾，找到「○○的字.otf」。
  2. 在檔案上按右鍵，選「安裝」。
    Windows 11 如果沒看到「安裝」，先點「顯示其他選項」。也可以點兩下打開預覽，再按左上角的「安裝」。
  3. 等幾秒鐘就裝好了，不會跳出通知。
  4. 打開 Word（已經開著的話，先關掉再重開），在字型選單找「○○的字」。
  1. 打開「Finder」→「下載項目」，找到「○○的字.otf」。
  2. 點兩下檔案，會打開「字體簿」的預覽視窗。
  3. 按右下角的「安裝字體」。
    如果跳出「字體驗證」有警告，手寫字型常會這樣，勾選後按「安裝已勾選的項目」就可以。
  4. 打開 Pages、Keynote 或 Word（已經開著的話，先關掉再重開），在字型選單找「○○的字」。
小提醒
  • 還沒寫過的字，電腦會自動用其他字型顯示，所以多寫一些字，看起來會更完整。
  • 寫了更多字以後，重新下載字型檔再安裝一次，就會換成新的。
  • 把文件傳給別人時，對方電腦沒有這個字型，會變成別的字。先存成 PDF 再傳，就能保留自己的字。
  • Google 文件這類網頁版的軟體，沒辦法用自己電腦裝的字型。
  • 不想要了：Windows 到「設定 → 個人化 → 字型」點字型後按「解除安裝」；Mac 在字體簿選字型後按刪除。

存檔與備份

每寫一筆就會自動存在這台裝置，下次打開會接著寫。
但清除瀏覽紀錄、換手機，或 iPhone／iPad 太久沒打開，資料可能會不見，所以每次寫完請按「今天寫完了」下載備份檔，存到「檔案」或雲端硬碟。
換手機、換瀏覽器或資料不見時，按「上傳備份檔」選之前下載的 .json 檔，就能接著寫。把這個網頁「加入主畫面」再從桌面打開，比較不容易被清掉。
